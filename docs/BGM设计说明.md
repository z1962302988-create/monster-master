# 《怪物情绪诊所》BGM 设计说明

整体定位：治愈系室内乐 / 梦幻轻氛围。统一使用“上行 1-2-5”短动机，代表雾雾逐渐确认自己被看见。所有音乐均为纯音乐、低动态、可循环，并主动避开密集的人声频段，保证对白清晰。

| 场景 | 曲目 | 方向 | 速度 |
|---|---|---|---:|
| 登录页 / 午夜诊所 | `BGM_Login_MidnightClinic` | 音乐盒、月光感、轻微神秘 | 72 BPM |
| 诊所大厅 | `BGM_Main_GentleReception` | 温暖电钢琴、轻盈而不幼稚 | 84 BPM |
| 安静陪伴病房 | `BGM_Ward_QuietCompanionship` | 留白较多、柔软、适合长对白 | 66 BPM |
| 方块解谜 | `BGM_Puzzle_MistAndName` | 柔和拨弦脉冲、专注但不焦虑 | 96 BPM |

音量建议：BGM 总线应明显低于对白；当前播放器默认音量为 0.1。正式发布时建议将 WAV 转为 Vorbis，质量 70%，并在 Unity 导入设置中启用 Streaming。

重新生成：运行 `Tools/generate_bgm.py`。脚本固定编曲规则，不含第三方采样，便于后续调整旋律与和声。
